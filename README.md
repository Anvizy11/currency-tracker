# Currency Rate Tracker 📈

Учебный сервис на Python для отслеживания актуальных курсов валют через API Центробанка РФ.

## Что делает проект:
- Получает свежие котировки валют (USD, EUR) через API ЦБ РФ.
- Сохраняет данные в локальный файл `rates.json` с меткой времени проверки.
- Читает сохранённый JSON и позволяет проводить быстрые расчёты.

## Стек технологий:
- Python 3
- Requests (работа с HTTP API)
- Модули `json` и `datetime`
